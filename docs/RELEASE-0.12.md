# PMWeather-IV 0.12

- Adds per-aircraft auto trim, off by default and toggled with Right Alt.
- Shows a brief auto-trim key hint when entering a supported pilot seat.
- Hides the auto-trim panel when disabled and shows live trim and adjustment status when enabled.
- Automatically shows live wind while piloting an IV aircraft and hides it after dismount.
- Adds `/pmaero live on` and `/pmaero live off` for manual wind display.
- Keeps manually enabled wind display visible after dismount until the player changes worlds or disconnects.
