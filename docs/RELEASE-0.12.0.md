# PMWeather-IV 0.12.0

Initial public release of the clean PMIV addon line.

## Changes

- Adds the shared `/aerowind` live wind display and Aerowind test controls when PMAero is installed.
- Uses the aircraft structure heading for the live wind display while seated in an IV aircraft; other seats remain player-relative.
- Keeps PMIV’s persistent rigid-body, contact and crash integration from the 0.11.x development line.

## Requirements

Minecraft 1.21.1, NeoForge, Immersive Vehicles, Sable, and PMWeather Aeronautics 1.0 or later. Install those dependencies separately.

The release JAR contains PMIV and its notices only; it does not bundle dependency JARs or development utilities.
